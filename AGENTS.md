# AGENTS.md

Инструкции для AI-агентов и людей, которые меняют этот репозиторий.

## Что это

Статический сайт производственного календаря (Preact + Vite, пререндер страниц, без SSR).
Данные — JSON в `data/`, логика — чистые функции в `src/domain/`, интерфейс — `src/components/`.

## Команды

```bash
npm run dev         # дев-сервер
npm test            # все юнит- и компонентные тесты
npm run lint        # ESLint + Prettier --check
npm run typecheck   # tsc --noEmit
npm run build       # сборка с пререндером
npm run test:dist   # проверка dist/ (после build)
npm run size-limit  # бюджеты: JS ≤ 40 kB gzip, CSS ≤ 10 kB gzip
```

Перед тем как считать задачу готовой, должны проходить `lint`, `typecheck`, `test`, `build`, `test:dist` и `size-limit`.

## Правила

- **Код-стайл:** Prettier (`.prettierrc`: табы, без точек с запятой, одинарные кавычки). Импорты сортирует `simple-import-sort`.
- **Комментарии и тексты коммитов** — на русском, коротко и по делу.
- **Состояние** — `@preact/signals` в `src/state/store.ts`. Присваивание `.value` — нормальный API, правило `react-hooks/immutability` выключено намеренно.
- **Страны:** выбираются в выпадающем списке с чекбоксами (`CountryPicker`). `settings.countries` — отмеченные страны, первая — основная; больше одной — значит, идёт сравнение, отдельного флага нет. Последнюю страну снять нельзя. По умолчанию отмечена одна страна. В расчётах и разметке берите `store.countries`: там уже учтена шестидневка.
- **Шестидневка** (`settings.workWeek`): правила в `withSixDayWeek` (`src/domain/calendar.ts`). Выходной только воскресенье, переносы по постановлению не действуют. Норма часов считается по пятидневке, как велит приказ № 588н.
- **Отпуск:** показываем списанные дни, праздники внутри и отдых, если он длиннее отпуска. Рабочие дни внутри отпуска показываются только у стран с `leave.pay.days: "workdays"`. Новые правила страны задавайте в её JSON, а не условиями по id в коде.
- **Гидрация:** всё, что зависит от браузера (сегодняшняя дата, localStorage, тема), применяется только после монтирования (`CalendarPage`). Разметка пререндера и первого рендера на клиенте должна совпадать.
- **i18n:** новый ключ сразу добавляйте во все словари `src/i18n/locales/*.ts`. Тип `Dict` берётся из `ru.ts`, тест проверяет, что все словари полные. Даты и названия месяцев форматируются через словари, а не через `Intl.DateTimeFormat`. Сокращения пишутся без точки: «раб», «вых», «ч».
- **Годовой вид** разбит на кварталы: три месяца в ряд, уже 720 px — по одному, с липким заголовком квартала. Итоги у квартала и месяца считает `yearTotals` по основной стране.
- **Страницы стран:** новой стране заполните `pages` (язык страны, русский, английский). Маршруты, пререндер, hreflang и sitemap строятся из `pageGroups` в `src/app/routes.ts`, отдельно их не правьте.
- **Данные:** меняйте JSON только со ссылкой на источник в `sources`. Итоги года не храните, их считает код. Если есть официальные нормы, добавьте `officialNorms`, тест сверит расчёт. Формат описан в `data/README.md`.
- **Аналитика:** новое событие сначала опишите в `src/analytics/events.json`, потом вызывайте `track()` и запустите `npm run goals`, чтобы обновить `docs/metrika-goals.md`. Тест падает, если события в коде, JSON и списке целей расходятся.
- **Анимации** включаются только после загрузки (атрибут `data-ready` на `<html>`), чтобы сохранённые настройки применялись без движения. Учитывайте `prefers-reduced-motion` и не сдвигайте соседние блоки скачком.
- **Печать:** стили в блоках `@media print`. Свёрнутые спойлеры (`Spoiler`) печатаются раскрытыми, поэтому спойлер — кнопка и блок, а не `<details>`.
- **Цвета стран** задаются CSS-переменными `--c-<id>` в `src/styles/global.css`. Элементы получают цвет через атрибут `data-c`, а не через inline-стили: так HTML годового вида меньше.
- **Зависимости:** не добавляйте новые без явной причины. Бюджет JS проверяет size-limit.
- **Размер данных:** профили стран с названиями праздников на всех языках лежат в основном JS (около 5 kB gzip на 5 стран). Когда будете добавлять новые страны, вынесите названия по языкам, чтобы они грузились вместе со словарём.
- **Не больше 5 стран** в наложении (`MAX_COUNTRIES` в `src/config.ts`).

## Как проверить изменения в интерфейсе

1. `npm run build && npm run preview`, откройте `http://localhost:4173/ru/2027/`.
2. Проверьте ширины 375, 768 и 1280 px, светлую и тёмную тему.
3. Проверьте выбор отпуска мышью (тусклое превью при наведении) и тапами (без наведения).
4. Посмотрите, что в консоли нет ошибок гидрации.
